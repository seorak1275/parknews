## 수집·가공 방법

1. 네이버 검색 API 로 공원 24곳 × 5각도 + 공통 = 127개 질의, 질의당 최대 1,000건
2. 제목 기준 중복 제거, 채용·입찰·편성표 등 비기사 제외
3. 국립공원 관련어가 없는 기사 제외
4. 제목·요약의 낱말로 분야 → 세부분류 2단계 분류
5. 해외분은 한국어 표기(네이버)와 영문(구글 뉴스) 두 갈래로 수집
