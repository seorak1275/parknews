# 👉 **[https://parknews.vercel.app](https://parknews.vercel.app)**

![파크뉴스 지도 대시보드 — 국내 국립공원 24곳이 표시된 첫 화면](screenshot-map.jpg)

## 이게 뭔가요?

전국 **국립공원 24곳**과 **해외 국립공원 2,034곳**에 대한
뉴스·통계·순위를 지도 위에 올려놓은 웹사이트입니다.

- 지도에서 **공원을 누르면** 그 공원 관련 최신 기사가 바로 뜹니다
- 요즘 **어떤 공원이 화제인지** 순위로 보여줍니다
- 매일 아침 **전날 기사 요약본**이 자동으로 만들어지고, PDF로 받을 수 있습니다

휴대폰에서도 그대로 열립니다. 화면이 좁아지면 목록과 상세가 아래에서 올라오는 형태로 자동 전환됩니다.

### 1. 지도 대시보드 — 공원별 뉴스

처음 열면 대한민국 지도에 **국립공원 24곳**이 표시됩니다.

| 이렇게 하면 | 이렇게 됩니다 |
|---|---|
| 공원 이름이나 영역을 **클릭** | 옆에 그 공원의 최신 기사·통계가 열립니다 |

| 화면 위 **[밝은 지도]** | 어두운 지도 ↔ 밝은 지도 전환 (인쇄·보고용으로 유용) |

## 알아두시면 좋은 점

**뉴스는 어디서 오나요?**
구글·빙 뉴스에서 국립공원 관련 기사를 모아옵니다. 공단이 작성한 기사가 아니라 **언론 보도를 모아 보여주는 것**입니다.

**"설악산 맛집" 같은 기사는 안 뜨나요?**
안 뜹니다. 지명만 겹치고 국립공원과 관계없는 기사는 걸러내도록 만들어져 있습니다. 다만 완벽하진 않아서 가끔 섞일 수 있습니다.

**화제성 순위는 어떻게 매기나요?**
같은 사안을 **몇 개 언론사가 보도했는지**로 계산합니다. 조회수가 아니라 보도 언론사 수 기준입니다.

**요약문은 사람이 쓴 건가요?**
아닙니다. AI가 자동으로 작성합니다. **중요한 판단에 쓰실 때는 원문 기사 링크를 꼭 확인해 주세요.**

**차트 숫자가 실제 값인가요?**
기본 상태의 트렌드 차트는 **참고용 모의 수치**이며, 화면에 그렇게 표시돼 있습니다. 실측값으로 바꾸려면 네이버 데이터랩 연동이 필요합니다 (담당자용 참고).

**해외 공원이 나라마다 개수가 들쭉날쭉해요.**
공개 지도 데이터(OSM)를 기반으로 해서, 나라별 등록 상태에 차이가 있습니다. 캐나다는 주립공원이 일부 섞여 있고 오세아니아는 11곳뿐입니다.

**뭔가 안 보이거나 이상하면?**
새로고침을 한 번 해보시고, 그래도 안 되면 담당자에게 알려주세요.

### 한 줄 요약

빌드 과정이 없는 **정적 사이트**(HTML + CSS + JS)이며, 뉴스 수집·요약만 서버리스 함수(`api/`)로 처리합니다.

### 로컬에서 실행

```bash
npx serve .            # → http://localhost:3000
python -m http.server  # → http://localhost:8000
```

`index.html`을 더블클릭해도 열리지만, 일부 브라우저가 `file://`에서 외부 요청을 막으므로 서버 방식을 권장합니다.
**API 키가 하나도 없어도 모든 화면이 동작합니다** (MapLibre + CARTO 무료 타일).

### 일일기사요약 자동 생성

```
매일 07:00 KST — Vercel Cron → /api/digest?cron=1
  ① 전날(D-1) 국립공원 기사 수집 (구글 뉴스 RSS 24개 질의)
  ② 같은 사안끼리 묶기 → 언론사 복수 표기 · 보도 건수 산출
  ③ D-1 · D-2 요약본과 대조해 중복 이슈 제거
  ④ Claude 가 원본 요약본 문체로 요약 + 주요/참고 분류
  ⑤ data/digest/YYYY-MM-DD.json 커밋 → 사이트 자동 반영
```

**환경변수 (Vercel → Settings → Environment Variables)**

| 변수 | 필수 | 용도 |
|---|:--:|---|
| `ANTHROPIC_API_KEY` | ✅ | 요약 생성 — <https://console.anthropic.com/> |
| `CRON_SECRET` | 권장 | 수동 실행 보호 |
| `GITHUB_TOKEN` | 선택 | 아카이브 커밋용 PAT (`contents: write`) |
| `GITHUB_REPO` | 선택 | 예) `yourname/parknews` |
| `GITHUB_BRANCH` | 선택 | 기본 `main` |
| `DIGEST_EFFORT` | 선택 | 기본 `medium` — Vercel Pro면 `high` 권장 |

> 💰 하루 1회 호출이라 **월 몇백 원 수준**입니다.
> ⏱️ Vercel Hobby는 함수 최대 60초 — 기본값이면 충분합니다.

### 지도 데이터 출처

**국내 24곳 — 환경부 공식 경계도**

- `assets/data/parks-kr.geojson` (0.83MB) — 원본 70만 정점을 55m 수준으로 단순화
- 2023년 팔공산(제23호), 2025년 금정산(제24호)까지 **24곳 전부** 수록
- 마커는 최대 폴리곤의 **내부 대표점** — 다도해·한려해상처럼 섬이 흩어진 공원도 바다 위에 찍히지 않습니다

**해외 2,034곳 — OSM + Natural Earth**

`assets/data/parks-global.json` (0.9MB) — 해외 탭을 처음 열 때만 지연 로드. 주요 공원 109곳은 한국어명·설명 큐레이션.

| 대륙 | 공원 수 |
|---|--:|
| 북아메리카 | 537 |
| 아시아 | 534 |
| 유럽 | 529 |
| 남아메리카 | 233 |
| 아프리카 | 188 |
| 오세아니아 | 11 |

<details>
<summary><b>왜 IUCN/WDPA 원본을 직접 쓰지 않았나 · 업그레이드 방법</b></summary>

권위 있는 원본은 IUCN/UNEP-WCMC의 **WDPA**(카테고리 II ≈ 국립공원 약 3,500곳)지만, 토큰이 신청·승인제라 작업 시점에 바로 쓸 수 없어 **OSM Overpass**(`boundary=national_park`)로 수집했습니다.

**알려진 한계** — OSM 태깅 관습이 나라마다 달라 밀도가 고르지 않습니다. 캐나다는 주립공원이 섞여 과다 집계, 오세아니아는 11곳뿐(`protect_class=2` 보완 쿼리가 타임아웃).

**WDPA 토큰을 받으면** (<https://api.protectedplanet.net/request>):

```bash
set WDPA_TOKEN=발급받은_토큰
python tools/import_wdpa.py assets/data/parks-global.json
```

IUCN 정본으로 교체되고 기존 한국어명은 좌표 대조로 자동 유지됩니다.

> ⚖️ WDPA는 비상업적 이용 시 출처 표기 조건: `UNEP-WCMC and IUCN, Protected Planet: WDPA, Cambridge, UK. www.protectedplanet.net`
</details>

### 배포

**Vercel (현재 운영 중 · 권장)**

<https://vercel.com/new> → 저장소 선택 → **Deploy**.
프레임워크 **Other**, 빌드 명령·출력 디렉터리는 **비워둡니다**. 이후 main에 푸시할 때마다 자동 배포됩니다.
`api/` 서버리스와 일일요약 크론이 전부 동작하는 것은 이 경로뿐입니다.

**GitLab Pages (사내망 · `.gitlab-ci.yml`)**

저장소의 `.gitlab-ci.yml`이 정적 파일을 `public/`으로 복사해 Pages로 게시합니다.
이 파일이 있으면 **Auto DevOps는 자동으로 꺼집니다** — 기존에 실패하던 `build`/`test`/`code_quality` 잡이 이 때문에 생긴 것이었습니다 (정적 사이트를 Node 앱으로 오인해 Docker 빌드를 시도).

Pages 배포 시 제약:

| 항목 | 상태 |
|---|---|
| 지도 · 검색 · 탐색 | ✅ 정상 |
| 뉴스 수집 | ⚠️ `/api/news` 없음 → 무료 CORS 프록시 폴백 |
| 일일요약 | ⚠️ **간이본만** (AI 요약문 없음) |
| 자동 생성 크론 | ❌ 미동작 (Vercel Cron 전용) |

> ⚠️ **사내망에서 확인 필요** — 지도 타일(`cartocdn.com`), 지도 라이브러리(`unpkg.com`), 글꼴(`cdn.jsdelivr.net`), 뉴스 프록시가 전부 외부 도메인입니다. 폐쇄망에서 차단되면 지도가 빈 화면으로 뜹니다. 이 경우 해당 라이브러리·타일을 저장소 안에 내려받아 넣는 작업이 별도로 필요합니다.

### 비용과 무료 한도

전부 무료로 운영 가능하도록 설계됐습니다. 유일한 종량 과금은 일일요약용 Anthropic API(하루 1회, 월 1달러 안팎)입니다.

| 서비스 | 무료 한도 | 초과 시 |
|---|---|---|
| Vercel Hobby | 대역폭 100GB/월 · 요청 100만/월 | 과금 없이 **일시 정지** (다음 달 리셋) |
| CARTO 지도 타일 | fair-use (비상업 전제) | 대규모 트래픽 시 대안 이전 검토 |
| 구글/빙 RSS · Nominatim | 무료 (비공식/공공) | CDN 캐시·클릭당 1회 조회로 사용량 최소화 |

> 대략 **일 방문자 1,000명까지는 걱정 없이 무료**, 일 2,000~3,000명이 꾸준하면 Vercel Pro($20/월) 검토 시점입니다.
> Vercel Hobby는 **비상업 용도 전용**이므로 광고·수익화 시에는 Pro 전환이 필요합니다.
