## 2. 주요 기능

### 지도

- **국내 24곳 공식 경계 폴리곤** — 환경부 경계도 원본. 영역 클릭으로 상세 열림
- **해외 2,034곳 클러스터** — 원을 누르면 확대, 점을 누르면 상세. **선택 시 실제 경계 폴리곤**을 OSM에서 즉석 조회해 표시
- **보전기관 24곳** — 국내 기관 / 해외 공원청 / 국제기구·NGO 세 섹션으로 구분
- **밝은 지도 토글** — 다크(기본) ↔ 라이트 지도. 라이트에서는 마커·경계가 자동으로 어두운 톤 전환
- **모든 지점 표시 토글** — 국내+해외+기관을 한 지도에 동시 표시 (카메라는 움직이지 않음)
- **독도 표기** — 시군구 수준으로 확대하면 지명 라벨 표시

### 검색

- **한글로 해외 공원 검색** — `요세미티`, `옐로스톤`처럼 한글 표기로 검색 (유명 공원 130여 곳 별칭 사전 + 한글→로마자 변환)
- **오타 허용** — `yosemiet` → Yosemite, `설학산` → 설악산 (편집거리 기반)
- 국가·지역명 검색(`태국`), 발음기호 무시(`갈라파고스` → Galápagos)

### 뉴스

- **실시간 핫이슈 띠** — 보도 언론사 수 기준, 1위에 HOT 배지, 15분 갱신
- **인기뉴스 순위** — 국내/국외, 같은 사안을 몇 개 언론사가 보도했는지로 화제성 산정
- **국립공원 관련도 필터** — 공원 문맥어(탐방·멸종위기·케이블카 …)가 없으면 지명이 겹쳐도 제외. "설악산 맛집" 같은 기사가 걸러집니다
- **섹터 대시보드** — 행정 / 재난안전 / 자원보전 / 탐방시설 4분야 자동 분류 (키워드 스코어)

### 공유·모바일

- **공원 딥링크** — 공원을 선택하면 주소가 `#p=공원id`로 바뀌어, URL 복사만으로 그 화면을 공유
- **모바일 최적화** — 탐색·상세가 하단 시트로 전환, 핸들 스와이프로 닫기, 노치 대응

## 3. 뉴스는 어떻게 수집되나

| 순위 | 경로 | 조건 |
|:--:|---|---|
| ① | **`/api/news` 자체 서버리스** — 서버에서 구글·빙 뉴스 RSS 직접 수집, CDN 5분 캐시 | Vercel 배포 시 (기본) |
| ② | **네이버 검색 API** (`/api/naver-news`) | 키 등록 시 — 국내 커버리지 최상 |
| ③ | rss2json → 무료 CORS 프록시 3중 폴백 | ①②가 없거나 실패할 때 |

CDN 캐시(`s-maxage=300`) 덕분에 방문자가 늘어도 원본 RSS 호출은 검색어당 5분에 1회 수준으로 묶입니다.

   (트렌드 차트 실측값까지 원하면 **데이터랩**도 추가)
2. Vercel → Settings → Environment Variables 에 등록:

## 4. 일일기사요약 (자동 생성 + PDF)

상단 **[일일 요약]** 버튼. 매일 아침 자동 생성되며, A4 요약표 + 번호별 주요기사 상세(요약 전문·관련 보도 링크)로 구성됩니다.

```
매일 07:00 KST — Vercel Cron → /api/digest?cron=1
  ① 전날(D-1) 국립공원 기사 수집 (구글 뉴스 RSS 24개 질의)
  ② 같은 사안끼리 묶기 → 언론사 복수 표기 · 보도 건수 산출
  ③ D-1 · D-2 요약본과 대조해 중복 이슈 제거
  ④ Claude 가 원본 요약본 문체로 요약 + 주요/참고 분류
  ⑤ data/digest/YYYY-MM-DD.json 커밋 → 사이트 자동 반영
```

### 환경변수 (Vercel → Settings → Environment Variables)

| 변수 | 필수 | 용도 |
|---|:--:|---|
| `ANTHROPIC_API_KEY` | ✅ | 요약 생성 — <https://console.anthropic.com/> |
| `CRON_SECRET` | 권장 | 수동 실행 보호 |
| `GITHUB_TOKEN` | 선택 | 아카이브 커밋용 PAT (`contents: write`) |
| `GITHUB_REPO` | 선택 | 예) `yourname/parknews` |
| `GITHUB_BRANCH` | 선택 | 기본 `main` |
| `DIGEST_EFFORT` | 선택 | 기본 `medium` — Vercel Pro면 `high` 권장 |

> 💰 하루 1회 호출이라 **월 몇백 원 수준**입니다.
> ⏱️ Vercel Hobby는 함수 최대 60초 — 기본값이면 충분합니다.

<details>
<summary><b>중복 제거 규칙 · 수동 실행 · 간이본</b></summary>

**중복 제거**

| 상황 | 처리 |
|---|---|
| 어제 실린 사안이 오늘도 보도 | 제외 (사유를 문서 하단에 기록) |
| 같은 소재, **다른 공원** | 둘 다 게재 |
| 후속 보도인데 새 사실(수치·조치) 추가 | 게재, 진전을 요약에 명시 |

**수동 실행**

```bash
curl "https://<도메인>/api/digest?generate=1&key=<CRON_SECRET>"   # 즉시 생성
curl "https://<도메인>/api/digest?date=2026-07-29"                # 특정 날짜 조회
curl "https://<도메인>/api/digest?list=1"                         # 아카이브 목록
```

**배포 전 / 로컬** — `/api/`가 없으면 **간이본**으로 자동 전환됩니다. 헤드라인·언론사·건수는 집계되지만 AI 요약문은 비어 있고, 화면에 `간이본` 배지가 붙습니다. PDF·인쇄·날짜 이동은 동일하게 동작합니다.
</details>

## 5. 지도 데이터 출처

### 국내 24곳 — 환경부 공식 경계도

- `assets/data/parks-kr.geojson` (0.83MB) — 원본 70만 정점을 55m 수준으로 단순화
- 2023년 팔공산(제23호), 2025년 금정산(제24호)까지 **24곳 전부** 수록
- 마커는 최대 폴리곤의 **내부 대표점** — 다도해·한려해상처럼 섬이 흩어진 공원도 바다 위에 찍히지 않습니다

### 해외 2,034곳 — OSM + Natural Earth

`assets/data/parks-global.json` (0.9MB) — **해외 탭을 처음 열 때만 지연 로드**. 주요 공원 109곳은 한국어명·설명 큐레이션.

| 대륙 | 공원 수 |
|---|--:|
| 북아메리카 | 537 |
| 아시아 | 534 |
| 유럽 | 529 |
| 남아메리카 | 233 |
| 아프리카 | 188 |
| 오세아니아 | 11 |

목록은 **대륙 ▸ 지역 ▸ 국가 ▸ 공원** 4단계 드릴다운으로, 지도는 네이티브 클러스터로 그려 2천 점도 가볍습니다.
공원을 선택하면 **경계 폴리곤을 OSM Nominatim에서 즉석 조회**해 표시합니다 (클릭당 1회 + 캐시).

<details>
<summary><b>왜 IUCN/WDPA 원본을 직접 쓰지 않았나 · 업그레이드 방법</b></summary>

권위 있는 원본은 IUCN/UNEP-WCMC의 **WDPA**(카테고리 II ≈ 국립공원 약 3,500곳)지만, 토큰이 신청·승인제라 작업 시점에 바로 쓸 수 없어 **OSM Overpass**(`boundary=national_park`)로 수집했습니다.

**알려진 한계** — OSM 태깅 관습이 나라마다 달라 밀도가 고르지 않습니다. 캐나다는 주립공원이 섞여 과다 집계, 오세아니아는 11곳뿐(`protect_class=2` 보완 쿼리가 타임아웃).

**WDPA 토큰을 받으면** (<https://api.protectedplanet.net/request>):

```bash
set WDPA_TOKEN=발급받은_토큰
python tools/import_wdpa.py assets/data/parks-global.json
```

IUCN 정본으로 교체되고 기존 한국어명은 좌표 대조로 자동 유지됩니다.

> ⚖️ WDPA는 비상업적 이용 시 출처 표기 조건: `UNEP-WCMC and IUCN, Protected Planet: WDPA, Cambridge, UK. www.protectedplanet.net`
</details>

## 7. 커스터마이징

### 국내 공원 추가

`assets/js/regions.js`의 `REGIONS_KR`에 블록을 추가하면 마커·뉴스·차트가 전부 자동으로 붙습니다.

```js
{ id: 'chiaksan', name: '치악산국립공원', cat: 'kr',
  lng: 128.0499, lat: 37.3355,
  q: '치악산 국립공원', lang: 'ko',
  desc: '강원 원주·횡성·영월 · 1984년 지정' },
```

### 해외 공원 한글 검색어 추가

`assets/js/explorer.js`의 `KO_ALIASES`에 `'한글표기': '영문검색어'` 한 줄이면 됩니다.

### (선택) Mapbox 토큰 — 지구본·안개 표현

<https://account.mapbox.com/> 무료 토큰(월 50,000 로드)을 `assets/js/config.js`의 `MAPBOX_TOKEN`에 넣으면 Mapbox 엔진으로 전환됩니다. 없어도 모든 기능은 동일합니다.
**토큰에는 반드시 URL 제한(allowed URLs)을 걸어두세요** — 프론트에 노출되는 값입니다.

## 9. 비용과 무료 한도

이 프로젝트는 **전부 무료로 운영 가능**하도록 설계됐습니다. 유일한 종량 과금은 일일요약용 Anthropic API(하루 1회, 월 1달러 안팎)입니다.

| 서비스 | 무료 한도 | 초과 시 |
|---|---|---|
| Vercel Hobby | 대역폭 100GB/월 · 요청 100만/월 | 과금 없이 **일시 정지** (다음 달 리셋) |
| CARTO 지도 타일 | fair-use (비상업 전제) | 대규모 트래픽 시 대안 이전 검토 |
| 구글/빙 RSS · Nominatim | 무료 (비공식/공공) | CDN 캐시·클릭당 1회 조회로 사용량 최소화 |

> 대략 **일 방문자 1,000명까지는 걱정 없이 무료**, 일 2,000~3,000명이 꾸준하면 Vercel Pro($20/월) 검토 시점입니다.
> Vercel Hobby는 **비상업 용도 전용**이므로 광고·수익화 시에는 Pro 전환이 필요합니다.

## 10. 알려진 제약
