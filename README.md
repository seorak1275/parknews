# 🌐 PARKWATCH — 글로벌 하이브리드 맵 대시보드

> 실시간 교통상황과 국립공원 현안 뉴스를 지도 위에서 한눈에

다크 테마 지도 위에 **실시간 트래픽 레이어 + 지역별 뉴스 + 검색 트렌드 차트**를
글래스모피즘 UI로 올린 정적 웹 대시보드입니다. 빌드 도구 없이 파일만으로 동작합니다.

---

## 1. 지금 바로 실행하기

### 방법 A — 로컬 서버 (권장)

```bash
# 프로젝트 폴더에서
npx serve .
#  또는
python -m http.server 5500
```

브라우저에서 `http://localhost:3000` (또는 `:5500`) 접속.

### 방법 B — 그냥 열기

`index.html` 을 더블클릭해도 동작합니다.
(단, 일부 브라우저는 `file://` 에서 외부 요청을 막을 수 있어 **방법 A를 권장**합니다.)

> ✅ **API 키가 하나도 없어도 지도·뉴스·차트가 전부 뜹니다.**
> 키 없이 실행하면 MapLibre + CARTO 다크 타일로 자동 전환되며,
> Mapbox 전용인 **실시간 트래픽 레이어만** 비활성화됩니다.

## 2. 실시간 트래픽 켜기 (Mapbox 토큰)

1. <https://account.mapbox.com/> 가입 → **Access tokens** 에서 기본 토큰(`pk.`로 시작) 복사
   *무료 티어: 월 50,000 맵 로드*
2. `assets/js/config.js` 를 열고 한 줄만 교체

```js
MAPBOX_TOKEN: 'pk.eyJ1Ijoi...여기에_본인_토큰...',
```

3. 새로고침 → 상단 배지가 **`Mapbox · 실시간 트래픽 ON`** 으로 바뀌고
   도로 위에 초록/노랑/주황/빨강 흐름선이 표시됩니다.

**보안 팁 —** 토큰은 프론트엔드에 노출될 수밖에 없으므로,
Mapbox 대시보드에서 해당 토큰에 **URL 제한(allowed URLs)** 을 꼭 걸어두세요.

## 3. 뉴스 데이터는 어떻게 들어오나

| 경로 | 조건 | 설명 |
|---|---|---|
| **① 네이버 검색 API** | Vercel 배포 + 환경변수 등록 | `/api/naver-news` 서버리스 함수 경유. 키가 브라우저에 노출되지 않음 |
| **② rss2json** | 조건 없음 (기본) | CORS가 열려 있어 프록시 없이 호출 |
| **③ 구글 뉴스 RSS + 프록시** | ②가 실패할 때 | allorigins → codetabs → corsproxy 3중 폴백 |

### 🎯 국립공원 관련 기사만 남기는 필터

수집한 모든 기사에 **공원 문맥어 필수 조건**을 겁니다.
`국립공원 / 탐방 / 등산 / 멸종위기 / 케이블카 / 생태계 / 깃대종 …` 중 하나도 없으면
지명이 겹쳐도 탈락합니다. "설악산 맛집", "경주 아파트 분양" 같은 기사가 걸러집니다.

- 사이드바에 `수집 N건 중 국립공원 관련 M건만 표시`로 몇 건을 걸렀는지 보여줍니다
- 따옴표 안 핵심어(종명·프로그램명)가 다르면 별개 사안으로 분리합니다
  (`진노랑상사화` ≠ `대흥란`)

### (선택) 네이버 API 연동

1. <https://developers.naver.com/apps/#/register> 에서 애플리케이션 등록
   → **검색** API 추가 (트렌드 차트 실측값까지 원하면 **데이터랩** 도 추가)
2. Vercel → **Settings → Environment Variables** 에 등록

```
NAVER_CLIENT_ID      = 발급받은 Client ID
NAVER_CLIENT_SECRET  = 발급받은 Client Secret
```

## 4. 📄 일일기사요약 (자동 생성 + PDF 다운로드)

기존 `일일기사요약_YYYYMMDD.pdf` 와 같은 형식의 요약본을
**매일 아침 07:00(KST)에 자동 생성**하고, 상단 **[일일 요약]** 버튼으로 받습니다.

```
매일 07:00 KST (= 22:00 UTC)
  └─ Vercel Cron → /api/digest?cron=1
       ├─ ① 전날(D-1) 보도된 국립공원 기사 수집 (구글 뉴스 RSS 24개 질의)
       ├─ ② 같은 사안끼리 묶기 → 언론사 복수 표기 · 보도 건수 산출
       ├─ ③ D-1 · D-2 요약본과 대조해 중복 이슈 제거
       ├─ ④ Claude(claude-opus-5)가 원본 문체로 요약 + 주요/참고 분류
       └─ ⑤ data/digest/YYYY-MM-DD.json 커밋 → 사이트에 자동 반영
```

- **발행일 D호 = D-1 보도분** (7/29호 → 7/28 지면) — 기존 PDF와 동일한 규칙
- **총 N건 보도** = 언론사별 보도 횟수 합계 (항목 수와 별개)
- **구분** = `주요기사` / `참고기사` 2단계

### 중복 제거 규칙

| 상황 | 처리 |
|---|---|
| 어제 실린 사안이 오늘도 보도 | **제외** (사유를 문서 하단에 기록) |
| 같은 소재, **다른 공원** (7/28 다도해 대흥란 → 7/29 내장산 대흥란) | **둘 다 게재** |
| 후속 보도인데 새 사실(수치·조치·결정) 추가 | **게재**, 요약에 진전을 명시 |

### 환경변수

| 변수 | 필수 | 용도 |
|---|:--:|---|
| `ANTHROPIC_API_KEY` | ✅ | 요약 생성. <https://console.anthropic.com/> |
| `CRON_SECRET` | 권장 | 수동 실행 보호 |
| `GITHUB_TOKEN` | 선택 | 아카이브 커밋용 PAT (`contents: write`) |
| `GITHUB_REPO` | 선택 | 예) `yourname/parkwatch` |
| `GITHUB_BRANCH` | 선택 | 기본값 `main` |
| `DIGEST_EFFORT` | 선택 | 기본 `medium`, Pro 요금제면 `high` 권장 |

> 💰 하루 1회 호출이라 월 몇백 원 수준입니다.
>
> ⏱️ Vercel **Hobby는 함수 최대 60초**입니다. 기본값(`medium`)이면 충분히 끝납니다.
> Pro라면 `vercel.json` 의 `maxDuration` 을 `300`, `DIGEST_EFFORT` 를 `high` 로 올리세요.

### 수동 실행

```bash
curl "https://<도메인>/api/digest?generate=1&key=<CRON_SECRET>"   # 즉시 생성
curl "https://<도메인>/api/digest?date=2026-07-29"                # 특정 날짜
curl "https://<도메인>/api/digest?list=1"                         # 아카이브 목록
```

### 배포 전 / 로컬에서는

`/api/` 가 없으므로 **간이본**으로 자동 전환됩니다 — 헤드라인·언론사·건수는 집계되지만
**요약문은 비어 있고** 화면에 `간이본` 배지가 붙습니다. 버튼·PDF·날짜 이동은 그대로 동작합니다.

`[PDF 다운로드]` → `일일기사요약_20260729.pdf` (A4 세로, 여러 장 자동 분할, 한글 정상).
`[인쇄]` 는 브라우저 인쇄창을 띄우며 텍스트 선택이 가능한 PDF가 나옵니다.

## 5. 🗺️ 공원 데이터 — 출처와 구조

### 국내 24곳 (환경부 공식 경계도)

`전국국립공원 경계 파일.zip` (EPSG:5179) → WGS84 변환 + 단순화 → `assets/data/parks-kr.geojson`

- **24곳 전부** 수록. 2023년 팔공산 = 제23호, **2025년 금정산 = 제24호**
- 마커 좌표는 각 공원 **최대 폴리곤의 대표점**(내부 보장)으로 산출 —
  다도해·한려해상처럼 섬이 흩어진 공원도 엉뚱한 바다 위에 찍히지 않습니다
- 원본 70만 정점 → 단순화(0.0006° ≈ 55m) → **0.83MB**
- 지도에 실제 공원 영역이 반투명 폴리곤으로 그려지고, **폴리곤을 클릭하면** 해당 공원이 열립니다
- 좌측 패널 **[국립공원 경계]** 스위치로 켜고 끕니다

```bash
python tools/convert_parks.py <원본.geojson> assets/data/parks-kr.geojson <목록.txt> 0.0006
```

### 해외 2,702곳 (대륙 ▸ 지역 ▸ 국가 ▸ 공원)

`assets/data/parks-global.json` — 1.1MB, **해외 탭을 처음 열 때만 지연 로드**.

| 대륙 | 공원 수 | 주요 지역 |
|---|--:|---|
| 북아메리카 | 1,155 | 북아메리카 999 · 중앙아메리카 138 · 카리브 18 |
| 유럽 | 556 | 동유럽 211 · 북유럽 198 · 남유럽 81 · 서유럽 66 |
| 아시아 | 545 | 동남아시아 262 · 동아시아 112 · 남아시아 79 · 서아시아 64 |
| 남아메리카 | 237 | 11개국 |
| 아프리카 | 196 | 중앙 69 · 동 47 · 남 44 · 서 25 · 북 11 |
| 오세아니아 | 11 | 호주·뉴질랜드 9 |

**난잡함을 없앤 방법 — 4단계 드릴다운**

```
아시아 545  →  동남아시아 262  →  태국 116  →  Khao Yai …
```

- 목록은 **현재 단계만** 그려서 DOM이 항상 수십 개를 넘지 않습니다
- 지도는 개별 마커 대신 **네이티브 클러스터 레이어** — 2,700점도 가볍게 처리
- 검색창은 단계와 무관하게 전체를 훑습니다 (`Banff`, `태국` 모두 검색됨)

### 왜 IUCN 원본을 직접 쓰지 않았나

**IUCN/UNEP-WCMC 의 WDPA(World Database on Protected Areas)** 가 권위 있는 원본이 맞습니다.
`IUCN 카테고리 II = National Park` 로 전 세계 약 **3,500곳**이 등록돼 있습니다.

다만 작업 시점에 바로 쓸 수 없었습니다:

| 경로 | 상태 |
|---|---|
| Protected Planet API v4 | **토큰이 신청·승인제**. 무료지만 폼 제출 후 발급 |
| WDPA 벌크 다운로드 | 수 GB GDB/Shapefile, 월 단위 갱신 |
| Wikidata SPARQL | 작업 시점 **서비스 장애**로 분당 1회 제한 (HTTP 429) |
| OSM Overpass | ✅ 사용 (토큰 불필요) |

그래서 **OSM Overpass**(`boundary=national_park`)로 2,656곳을 받고,
**Natural Earth 50m 국경**과 점-다각형 대조로 국가·지역·대륙을 붙인 뒤,
주요 공원 106곳은 한국어명·설명을 손으로 붙여 승급시켰습니다.

**알려진 한계** — OSM은 나라마다 태깅 관습이 달라 밀도가 고릅니다:

- 캐나다 714곳처럼 **주립공원까지 섞여** 과다 집계된 나라가 있습니다
- 반대로 **오세아니아는 11곳뿐**입니다. 호주·뉴질랜드는 `protect_class=2` 로 태깅하는데
  해당 보완 쿼리가 계속 504(Gateway Timeout)로 실패했습니다

### WDPA 토큰을 받으시면

<https://api.protectedplanet.net/request> 에서 발급 후:

```bash
set WDPA_TOKEN=발급받은_토큰
python tools/import_wdpa.py assets/data/parks-global.json
```

위 한계가 전부 해소된 **IUCN 카테고리 II 정본**으로 교체되고,
기존 한국어명 106곳은 좌표 대조로 자동 이어붙습니다.

> ⚖️ WDPA 데이터는 **비상업적 이용 시 출처 표기** 조건입니다.
> 상업적 이용은 UNEP-WCMC 별도 허가가 필요합니다.
> `UNEP-WCMC and IUCN (연도), Protected Planet: WDPA, Cambridge, UK. www.protectedplanet.net`

## 8. 지점 추가·확장하기

### 국내 공원

`assets/js/regions.js` 의 `REGIONS_KR` 에 블록을 추가하면
마커·뉴스·차트·필터가 전부 자동으로 붙습니다.

```js
{ id: 'chiaksan', name: '치악산국립공원', cat: 'kr',
  lng: 128.0499, lat: 37.3355,
  q: '치악산 국립공원', lang: 'ko',
  desc: '강원 원주·횡성·영월 · 1984년 지정' },
```

### 해외 공원

`assets/js/regions-global.js` (큐레이션 원본)에 추가한 뒤 재빌드:

```bash
python tools/merge_curated.py assets/data/parks-global.json assets/js/regions-global.js
```

| 필드 | 설명 |
|---|---|
| `id` | 고유 키 (영문/숫자, 중복 금지) |
| `cat` | `kr` · `global` · `city` |
| `q` | 뉴스 검색어 (생략 시 `name`) |
| `lang` | `ko` → 한국 뉴스 / `en` → 영어권 뉴스 |

## 10. 주요 기능

- **실시간 핫이슈 띠** — 최상단, 보도 언론사 수 기준 1위에 HOT 배지
- **국내/해외 분리 탐색** — 탭 전환 + 대륙▸지역▸국가▸공원 드릴다운
- **공식 경계 폴리곤** — 국내 24곳 실제 공원 영역, 클릭 시 상세 열림
- **해외 클러스터 지도** — 2,700점을 클러스터로 렌더, 클릭하면 확대
- **일일기사요약** — 매일 07:00 자동 생성, D-1·D-2 중복 제거, PDF 다운로드
- **국립공원 관련도 필터** — 공원 문맥어 없는 기사는 전부 제외
- **실시간 트래픽 레이어** — 혼잡도 4단계, 지점별 혼잡 지수 산출
- **호버 미니 팝업** — 마커에 올리면 대표 헤드라인 + 혼잡도
- **트렌드 차트** — 크로스헤어 툴팁, 최고점만 직접 라벨, 단일 축
- **반응형** — 860px 이하에서 사이드바가 하단 시트로 전환

## 11. 알려진 제약

- **무료 CORS 프록시는 가끔 느리거나 실패**합니다. rss2json을 1순위로 두고 3중 폴백을 넣었지만,
  안정성이 중요하면 `/api/` 서버리스 경로(네이버 API)가 확실합니다
- **트래픽 데이터는 Mapbox 전용**입니다. 토큰 없이는 표시되지 않습니다
- **혼잡 지수는 현재 화면에 렌더된 타일만** 샘플링하므로, 줌 6 미만이거나
  도로가 없는 산악 지역에서는 "관측 데이터 없음"이 정상입니다
- **차트 기본값은 시뮬레이션**입니다 (배지에 명시). 데이터랩 키를 넣으면 실측으로 바뀝니다
- **해외 공원 밀도가 나라마다 고르지 않습니다** — 5장의 "알려진 한계" 참고.
  WDPA 토큰으로 해소됩니다
